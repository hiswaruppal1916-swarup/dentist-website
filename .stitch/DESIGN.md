## 5. Mobile-First Layout Rules
- Target Viewport: 360px – 430px smartphone base
- Minimum touch target: 44px x 44px
- Bottom Navigation Dock on mobile for 1-thumb thumb zone
- Safe-area insets: `env(safe-area-inset-bottom)`
- Border Radii: 8px (sm), 12px (md), 16px (lg), 24px (xl), 9999px (full)
- Card elevation: `0 4px 16px rgba(11, 37, 69, 0.08)`
